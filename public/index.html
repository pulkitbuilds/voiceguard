How this prototype works
This console runs signal-processing heuristics client-side (Web Audio API): time-domain autocorrelation for pitch/jitter, FFT-based spectral flatness & rolloff, RMS-based pause segmentation, and zero-crossing variability. Scores flag deviations from natural conversational speech statistics. This is a research-grade heuristic demonstrator, not a trained deep-learning spoof classifier — a production deployment (see the companion backend) should replace/augment this layer with a model trained on labeled spoof-detection corpora (e.g. ASVspoof-style data, RawNet2/AASIST architectures) and cross-session speaker-consistency checks.
